# DESIGN — THE FROM BRAIN

> **아이덴티티는 뼈대에 둔다. 눈에 보이는 형상은 뇌다.**

더프롬의 규칙(1U · 왼쪽 정렬 · 직각 · 노랑의 태도)은 간격과 크기와 판을 정하는 데만 쓴다. 화면에서 보이는 것은 뇌 형상의 홀로그램 하나다. 근거는 방법론 CORE §2.2.4 — "사용자가 1U를 알아볼 수 있다면 실패다."

첫 시안은 노드까지 사각형(1U)으로 그렸다. 아이덴티티가 모티프가 되어 화면이 지저분해졌고, 2026-11-25 지홍 판정으로 버렸다. 이 문서는 그 뒤의 기준이다.

## 1. 원칙

| # | 원칙 | 판정 질문 |
|---|---|---|
| 1 | 형상이 먼저다 | 글자를 가려도 뇌로 읽히는가 |
| 2 | 색은 셋 | 찬 흰색 · 노랑 · 빨강 말고 다른 색이 유니버스에 있는가 |
| 3 | 노랑은 수렴에만 | 노랑이 통합 인사이트 · 사고의 경로 · 선택 · 실행 버튼 밖에 쓰였는가 |
| 4 | 원은 뉴런에만 | 노드를 가리키지 않는 원이 있는가 |
| 5 | 밝기가 곧 의미다 | 밝은 곳이 실제로 신호가 모인 곳인가 |

## 2. 토큰

`css/brain.css`의 `:root`와 `js/graph/view.js`의 `COLORS`가 원본이다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#08090B` | 화면 전체 |
| 면 | `#0D0F12` · `#14171B` | 패널 · 카드 |
| 홀로그램(찬 흰색) | `#CFE3F2` | 점 구름 · 뉴런 · 연결 · 글자 |
| 노랑 (FROM Yellow) | `#FFD200` | 통합 인사이트 · 사고의 경로 · 선택 · 사고 시작 |
| 빨강 (FROM Red) | `#E85E53` | 긴장 엣지 · 가드에 걸린 인사이트 · 오류 |
| 파랑 · 초록 (FROM Blue · Green의 밝은 값) | `#9EA3E3` · `#62C2A2` | **패널의 노드군 칩에만** — 유니버스에는 쓰지 않는다 |

- **1U = 8px.** 간격 0.5U · 1U · 1.5U · 2U · 3U · 4U. 패널 폭 58U, 상단 7U.
- **타입** (UI 스케일, CORE §2.2.5): 12 · 14 · 16 · 18 · 22px. 행간은 2px의 배수.
- **글꼴**: Pretendard(본문) · 고정폭(ID · 수치 · 영문 캡션). Pretendard는 1.x의 `src/renderer/fonts/`를 그대로 쓰고, 없으면 시스템 한글 글꼴로 내려간다.
- **판**: 모든 판과 버튼은 직각, 선은 1px. 둥근 것은 뉴런과 뉴런을 가리키는 번호표뿐이다.

## 3. 유니버스 — 뇌의 형상

왼쪽을 보는 옆모습. 윤곽 · 점 구름 · 노드 자리는 모두 `js/graph/brain.js`의 좌표 하나에서 나온다.

| 부위 | 놓이는 것 | 이유 |
|---|---|---|
| 전두엽 (앞) | THE FROM 아이덴티티 6 | 판단이 시작되는 곳 |
| 두정 · 후두엽 (위 · 뒤) | Airplane — 사조 16 | 보고 연상하는 곳. 발화하지 않은 사조는 빈 고리로 남는다 |
| 측두엽 (아래) | Tunnel 4 | 맥락을 알아듣는 곳 |
| 중심부 | 이슈 | 모든 신호가 대입되는 자리 |
| 뇌간 | 미션 · 문(N7) | 들어오고, 문을 지나 나간다 |

엽의 배치는 화면을 읽기 위한 은유다. 신경과학의 주장이 아니다.

**형상을 만드는 것**
- 점 구름 약 2,600개 — 앞 반구와 뒤 반구 두 겹. 뒤 반구는 흐리다.
- 고랑 세 줄(외측 · 중심 · 두정후두)은 점을 비워 만든다. 소뇌는 가로 결.
- 가는 윤곽선 하나와 받침 타원 셋.
- 홀로그램은 15초에 한 번, 좌우 ±0.15rad로 흔들린다. 두 겹의 시차가 깊이를 만든다. `prefers-reduced-motion`이면 멈춘다.

**표기**

| 대상 | 모양 |
|---|---|
| 기준 노드 | 흰 점 + 고리. 이름은 뇌의 바깥쪽으로 |
| 잠든 기준 노드 | 빈 고리 (이름 없음 — 올리면 나온다) |
| 신호 | 작은 흰 점. 에너지가 클수록 크고 밝다 |
| 이슈 | 고리 + 가운데 점. 근본 이슈는 굵다 |
| 통합 인사이트 | 노란 점 + 노란 빛 |
| 연결 (원인 · 조건 · 강화) | 중심 쪽으로 휘는 가는 선. 조건은 점선. 방향 화살은 고른 노드 주변에만 |
| 긴장 | 빨간 점선 |
| 사고의 경로 | 고른 인사이트의 인과 사슬 — 노란 선과 순서 번호 |

**밝기** — 신호 가까운 점일수록 밝다. 생각이 지나간 자리가 밝아진다(Tunnel: 레이어가 겹칠수록 밝아진다). 인사이트를 고르면 그 근거 신호 주변만 남는다.

**움직임** — 발화: 노드에서 노란 고리가 퍼진다. 사고 중: 세로 빛 띠가 뇌를 훑고 바깥 호가 빨리 돈다. 그 밖의 장식 애니메이션은 없다.

## 4. 패널

- 두괄식. 맨 위 한 문장이 결론이고, 비율에는 건수를 함께 적는다 (`20건(77%)`).
- 탭 셋: 미션 · 인사이트 · 노드. 고른 탭은 노란 밑줄.
- 소제목은 고정폭 11px · 자간 .12em. 설명을 위한 설명은 쓰지 않는다.
- 문장 규칙은 1.x `knowledge/method/writing.md`를 따른다 — 의미 먼저, 장면과 은유로 판단을 대신하지 않는다.

## 5. 하지 않는 것

- 노드를 사각형으로 그리지 않는다. 1U 형상 · 막대 쌓기를 모티프로 쓰지 않는다 (로고 마크 제외).
- 유니버스에 노드군별 색을 쓰지 않는다. 노드군은 자리(엽)로 구분한다.
- 그라디언트 면 · 그림자 · 둥근 카드 · 이모지를 쓰지 않는다.
- 특정 영화 · 게임의 인터페이스를 인용하지 않는다. 가져온 것은 "홀로그램 계기판"이라는 장르뿐이다.
- 이 디자인을 클라이언트 결과물에 옮기지 않는다 (N7). 더프롬 자사 도구의 얼굴이다.
