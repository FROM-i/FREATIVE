# DESIGN — THE FROM BRAIN

**더프롬 규칙은 간격 · 크기 · 패널에만 쓰고, 화면의 주인공은 뇌 형상 홀로그램으로 한다.**

근거는 CORE §2.2.4 "사용자가 1U를 알아볼 수 있다면 실패다." 첫 시안은 노드를 사각형(1U)으로 그려 화면이 지저분했고, 2026-11-25 대표 판정으로 폐기했다.

## 1. 원칙

| # | 원칙 | 판정 질문 |
|---|---|---|
| 1 | 형상 우선 | 글자를 가려도 뇌(또는 그 프로젝트가 고른 형상)로 보이는가 |
| 2 | 색은 4가지, 역할은 하나씩 | 브레인 맵에 흰색 · 노랑 · 핑크 · 빨강 외의 색이 있는가. 한 색이 두 역할을 하는가 |
| 3 | 노랑은 결과에만 | 노랑이 통합 인사이트 · 실행 버튼 외에 쓰였는가 |
| 3-1 | 핑크는 계보에만 | 핑크가 기본 노드 → 판단 → 인사이트로 이어지는 선과 지금 고른 것 외에 쓰였는가 |
| 4 | 원은 노드에만 | 노드가 아닌 원이 있는가 |
| 5 | 밝기 = 판단이 모인 정도 | 밝은 곳에 실제로 판단이 모여 있는가 |

## 2. 토큰

`css/brain.css`의 `:root`와 `js/graph/view.js`의 `COLORS`가 원본이다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#08090B` | 화면 전체 |
| 면 | `#0D0F12` · `#14171B` | 패널 · 카드 |
| 홀로그램(흰색) | `#CFE3F2` | 점 구름 · 노드 · 연결 · 글자 |
| 노랑 (FROM Yellow) | `#FFD200` | 통합 인사이트(결과) · 분석 시작. 패널에서는 인사이트 3건 가운데 1위만 채운 노랑, 나머지는 테두리 |
| 형광 핑크 | `#FF4FB0` | 계보: 기본 노드군 → 기준 노드 → 판단 → 인사이트로 이어지는 선, 지금 고른 노드, 근거 경로 |
| 빨강 (FROM Red) | `#E85E53` | 충돌 연결 · 검증에 걸린 인사이트 · 오류 |
| 파랑 · 초록 | `#9EA3E3` · `#62C2A2` | 쓰지 않는다(값만 남겨 둠). 패널의 노드군은 해시태그와 밝기로 가른다 |

- **1U = 8px.** 간격 0.5U · 1U · 1.5U · 2U · 3U · 4U. 패널 폭 58U, 상단 7U.
- **타입** (UI 스케일, CORE §2.2.5): 12 · 14 · 16 · 18 · 22px. 행간은 2px의 배수.
- **글꼴**: Pretendard(본문) · 고정폭(ID · 수치 · 영문 캡션). Pretendard는 1.x의 `src/renderer/fonts/`를 그대로 쓰고, 없으면 시스템 한글 글꼴로 내려간다.
- **패널**: 패널과 버튼은 직각, 선은 1px. 둥근 것은 노드와 순서 번호뿐이다.

## 3. 브레인 맵

왼쪽을 보는 뇌의 옆모습이다. 윤곽 · 점 구름 · 노드 자리는 모두 `js/graph/brain.js`의 좌표를 쓴다.

| 부위 | 놓이는 것 | 이유 |
|---|---|---|
| 전두엽 (앞) | THE FROM 아이덴티티 6 | 판단 기준 |
| 두정 · 후두엽 (위 · 뒤) | Airplane 사조 16 | 시각과 연상. 고르지 않은 사조는 빈 고리로 표시 |
| 측두엽 (아래) | Tunnel 4 | 맥락 이해 |
| 중심부 | 이슈 | 모든 판단이 향하는 곳 |
| 뇌간 | 미션 · N7 게이트 | 입력과 출력 |

엽 배치는 화면 구분용이다. 신경과학 근거는 없다.

**구성**
- 점 약 2,600개를 앞 · 뒤 2겹으로 놓는다. 뒤쪽은 흐리게 한다.
- 고랑 3줄(외측 · 중심 · 두정후두)은 점을 비워서 표현한다. 소뇌는 가로줄로 그린다.
- 윤곽선 1개, 받침 타원 3개.
- 15초 주기로 좌우 ±0.15rad 회전한다. 2겹의 시차로 입체감을 낸다. `prefers-reduced-motion`이면 멈춘다.

**표기**

| 대상 | 모양 |
|---|---|
| 기준 노드 | 흰 점 + 고리. 이름은 뇌 바깥쪽에 표시 |
| 쓰지 않은 기준 노드 | 빈 고리. 이름은 마우스를 올리면 표시 |
| 판단 | 작은 흰 점. 지지도가 높을수록 크고 밝다 |
| 이슈 | 고리 + 가운데 점. 근본 이슈는 굵다 |
| 통합 인사이트 | 노란 점 + 노란 빛 |
| 연결 (원인 · 조건 · 강화) | 중심 쪽으로 휘는 가는 선. 조건은 점선. 화살표는 선택한 노드 주변에만 표시 |
| 팩트 | 소뇌 자리에 가로줄이 든 고리. 판단이 기댄 팩트만 올린다. 사람이 확인하지 않은 팩트는 빨간 고리 |
| 충돌 | 빨간 점선 |
| 근거 경로 | 선택한 인사이트가 거친 판단을 노란 선과 순서 번호로 표시 |

**밝기** — 판단과 가까운 점일수록 밝다. 인사이트를 선택하면 근거 판단 주변만 밝게 남긴다.

**움직임** — 노드가 판단을 내면 노란 고리가 퍼진다. 분석 중에는 세로 빛 띠가 지나가고 바깥 호가 빠르게 돈다. 다른 애니메이션은 없다.

### 계보 표시

- 기본 노드군 이름(IDENTITY · AIRPLANE · TUNNEL)을 누르면 그 노드군에서 나온 기준 노드, 판단, 판단을 쓴 인사이트까지 핑크 선으로 잇는다.
- 기준 노드(예: 사조)를 누르면 거꾸로 노드군 이름까지 핑크 선이 올라가고, 아래로는 그 노드가 낸 판단과 인사이트까지 내려간다.
- 계보에 든 노드는 흐리게 하지 않는다.

### 인사이트 상세 창

- 노란 노드(통합 인사이트)를 누르거나 인사이트 탭의 "크게 보기"를 누르면 화면 가운데에 창이 뜬다.
- 맨 위에 계보 한 줄(노드군 → 기준 노드 → 인사이트), 그 아래에 컨셉, 보이는 표현, 사용자가 얻는 것, 차별화 · 실효성 수준, 판단을 미룬 것을 둔다.

### 프로젝트 형상

- 프로젝트가 층 쌓기 형상을 고르면 브레인 맵의 점 구름과 윤곽선이 층의 색을 쓴다. "색은 4가지" 원칙의 예외는 이 점 구름과 층 이름뿐이다.
- 노드(흰색) · 인사이트(노랑) · 계보(핑크) · 충돌(빨강)의 색은 형상이 바뀌어도 그대로다. 층 색을 이 넷과 겹치지 않게 고른다.
- 패널은 형상과 무관하게 같은 규칙을 쓴다.
- 클라이언트의 로고나 캐릭터를 형상으로 쓰지 않는다. 일반 사물의 모양과 색만 쓴다.

## 4. 패널

- 두괄식으로 쓴다. 첫 문장이 결론이고, 비율에는 건수를 같이 적는다 (`20건(77%)`).
- 탭 3개: 미션 · 인사이트 · 노드. 선택한 탭은 노란 밑줄.
- 소제목은 고정폭 11px · 자간 .12em.
- 패널에는 선과 글자만 둔다. 테두리 상자는 버튼과 입력란에만 쓴다. 구역은 위쪽 가는 선 하나로 가른다.
- 노드 · 노드군 · 태그는 해시태그로 쓴다(`#자메뷰`). 누를 수 있으면 올렸을 때 핑크. 상태(채택 · 차별화됨 · 목적 달성)는 글자로 쓰고 가운뎃점으로 가른다.
- 패널의 색은 넷: 흰색(글자) · 회색(보조) · 노랑(결과 · 채택) · 빨강(문제 · 약점). 핑크는 계보와 올렸을 때만. 파랑 · 초록은 쓰지 않는다. 노드군은 밝기로 가른다.
- 왼쪽 선이 붙은 줄(인용 줄)은 두 가지에만 쓴다: 기조(흰 선) · 더 밀 곳(노란 선).
- 글보다 모양으로 먼저 보여 준다. 쓰는 부품은 다섯 가지다.
  - 숫자 줄: 인사이트 수 · 쓰인 판단 · 충돌 · 팩트 근거. 맨 위에 4칸, 칸 사이는 세로선.
  - 단계 막대: 차별화(4칸) · 실효성(3칸). 수준을 칸으로 채운다. 첫 칸뿐이면 빨강.
  - 강점 · 약점 두 칸: 노드 연결에서 읽는다. 강점은 받치는 노드 · 푼 충돌 · 이긴 대결 · 고친 공격, 약점은 부딪히는 노드 · 진 대결과 이유 · 남은 공격 · 미달 점검 · 미룬 판단. 노드 이름은 칩이고 누르면 브레인 맵에서 그 노드로 간다.
  - 물음표 설명: 충돌 · 차별화 · 실효성 · 강점 · 약점 옆의 ?에 올리면 한 문단 설명이 뜬다.
  - 접는 구역: 판정문 · 근거 · 받은 공격 · 기획 틀 · 디렉션 · 경쟁 기록은 접어 둔다. 제목 오른쪽에 건수를 적는다.
- 인사이트 카드에 처음 보이는 것은 제목 · 판정 칩 · 컨셉 한 문장 · 단계 막대 · 강점/약점 · 더 밀 곳까지다. 나머지는 접는다.
- 문장은 "수단 + 효과"로 짧게 쓴다 (예: 친근한 안내 문구로 재방문 습관 유도). 낯선 낱말, 비유, 설명을 덧붙이는 설명은 쓰지 않는다. 세부 규칙은 `knowledge/prompts.js`의 문장 규칙과 1.x `knowledge/method/writing.md`.

## 5. 하지 않는 것

- 노드를 사각형으로 그리지 않는다. 1U 형상과 막대 쌓기를 장식으로 쓰지 않는다 (로고 제외).
- 브레인 맵에 노드군별 색을 쓰지 않는다. 노드군은 위치(엽)로 구분한다.
- 그라디언트 면 · 그림자 · 둥근 카드 · 이모지를 쓰지 않는다.
- 특정 영화 · 게임의 화면을 그대로 따라 하지 않는다. 홀로그램 계기판 분위기만 참고한다.
- 이 디자인을 클라이언트 결과물에 쓰지 않는다 (N7). 자사 도구 전용이다.
