# DESIGN — THE FROM BRAIN

**더프롬 규칙은 간격 · 크기 · 패널에만 쓰고, 화면의 주인공은 뇌 형상 홀로그램으로 한다.**

근거는 CORE §2.2.4 "사용자가 1U를 알아볼 수 있다면 실패다." 첫 시안은 노드를 사각형(1U)으로 그려 화면이 지저분했고, 2026-11-25 대표 판정으로 폐기했다.

## 1. 원칙

| # | 원칙 | 판정 질문 |
|---|---|---|
| 1 | 형상 우선 | 글자를 가려도 뇌로 보이는가 |
| 2 | 색은 3가지 | 브레인 맵에 흰색 · 노랑 · 빨강 외의 색이 있는가 |
| 3 | 노랑은 결과에만 | 노랑이 통합 인사이트 · 근거 경로 · 선택 · 실행 버튼 외에 쓰였는가 |
| 4 | 원은 노드에만 | 노드가 아닌 원이 있는가 |
| 5 | 밝기 = 판단이 모인 정도 | 밝은 곳에 실제로 판단이 모여 있는가 |

## 2. 토큰

`css/brain.css`의 `:root`와 `js/graph/view.js`의 `COLORS`가 원본이다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#08090B` | 화면 전체 |
| 면 | `#0D0F12` · `#14171B` | 패널 · 카드 |
| 홀로그램(흰색) | `#CFE3F2` | 점 구름 · 노드 · 연결 · 글자 |
| 노랑 (FROM Yellow) | `#FFD200` | 통합 인사이트 · 근거 경로 · 선택 · 분석 시작 |
| 빨강 (FROM Red) | `#E85E53` | 충돌 연결 · 검증에 걸린 인사이트 · 오류 |
| 파랑 · 초록 (FROM Blue · Green의 밝은 값) | `#9EA3E3` · `#62C2A2` | 패널의 노드군 칩에만 쓴다. 브레인 맵에는 쓰지 않는다 |

- **1U = 8px.** 간격 0.5U · 1U · 1.5U · 2U · 3U · 4U. 패널 폭 58U, 상단 7U.
- **타입** (UI 스케일, CORE §2.2.5): 12 · 14 · 16 · 18 · 22px. 행간은 2px의 배수.
- **글꼴**: Pretendard(본문) · 고정폭(ID · 수치 · 영문 캡션). Pretendard는 1.x의 `src/renderer/fonts/`를 그대로 쓰고, 없으면 시스템 한글 글꼴로 내려간다.
- **패널**: 패널과 버튼은 직각, 선은 1px. 둥근 것은 노드와 순서 번호뿐이다.

## 3. 브레인 맵

왼쪽을 보는 뇌의 옆모습이다. 윤곽 · 점 구름 · 노드 자리는 모두 `js/graph/brain.js`의 좌표를 쓴다.

| 부위 | 놓이는 것 | 이유 |
|---|---|---|
| 전두엽 (앞) | THE FROM 아이덴티티 6 | 판단 기준 |
| 두정 · 후두엽 (위 · 뒤) | Airplane 사조 16 | 시각과 연상. 고르지 않은 사조는 빈 고리로 표시 |
| 측두엽 (아래) | Tunnel 4 | 맥락 이해 |
| 중심부 | 이슈 | 모든 판단이 향하는 곳 |
| 뇌간 | 미션 · N7 게이트 | 입력과 출력 |

엽 배치는 화면 구분용이다. 신경과학 근거는 없다.

**구성**
- 점 약 2,600개를 앞 · 뒤 2겹으로 놓는다. 뒤쪽은 흐리게 한다.
- 고랑 3줄(외측 · 중심 · 두정후두)은 점을 비워서 표현한다. 소뇌는 가로줄로 그린다.
- 윤곽선 1개, 받침 타원 3개.
- 15초 주기로 좌우 ±0.15rad 회전한다. 2겹의 시차로 입체감을 낸다. `prefers-reduced-motion`이면 멈춘다.

**표기**

| 대상 | 모양 |
|---|---|
| 기준 노드 | 흰 점 + 고리. 이름은 뇌 바깥쪽에 표시 |
| 쓰지 않은 기준 노드 | 빈 고리. 이름은 마우스를 올리면 표시 |
| 판단 | 작은 흰 점. 지지도가 높을수록 크고 밝다 |
| 이슈 | 고리 + 가운데 점. 근본 이슈는 굵다 |
| 통합 인사이트 | 노란 점 + 노란 빛 |
| 연결 (원인 · 조건 · 강화) | 중심 쪽으로 휘는 가는 선. 조건은 점선. 화살표는 선택한 노드 주변에만 표시 |
| 충돌 | 빨간 점선 |
| 근거 경로 | 선택한 인사이트가 거친 판단을 노란 선과 순서 번호로 표시 |

**밝기** — 판단과 가까운 점일수록 밝다. 인사이트를 선택하면 근거 판단 주변만 밝게 남긴다.

**움직임** — 노드가 판단을 내면 노란 고리가 퍼진다. 분석 중에는 세로 빛 띠가 지나가고 바깥 호가 빠르게 돈다. 다른 애니메이션은 없다.

## 4. 패널

- 두괄식으로 쓴다. 첫 문장이 결론이고, 비율에는 건수를 같이 적는다 (`20건(77%)`).
- 탭 3개: 미션 · 인사이트 · 노드. 선택한 탭은 노란 밑줄.
- 소제목은 고정폭 11px · 자간 .12em.
- 문장은 "수단 + 효과"로 짧게 쓴다 (예: 친근한 안내 문구로 재방문 습관 유도). 낯선 낱말, 비유, 설명을 덧붙이는 설명은 쓰지 않는다. 세부 규칙은 `knowledge/prompts.js`의 문장 규칙과 1.x `knowledge/method/writing.md`.

## 5. 하지 않는 것

- 노드를 사각형으로 그리지 않는다. 1U 형상과 막대 쌓기를 장식으로 쓰지 않는다 (로고 제외).
- 브레인 맵에 노드군별 색을 쓰지 않는다. 노드군은 위치(엽)로 구분한다.
- 그라디언트 면 · 그림자 · 둥근 카드 · 이모지를 쓰지 않는다.
- 특정 영화 · 게임의 화면을 그대로 따라 하지 않는다. 홀로그램 계기판 분위기만 참고한다.
- 이 디자인을 클라이언트 결과물에 쓰지 않는다 (N7). 자사 도구 전용이다.
