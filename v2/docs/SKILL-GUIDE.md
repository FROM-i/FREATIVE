# RFP · 팩트북으로 브레인 프로젝트 채우기

RFP · 팩트북을 LLM에 올리면 브레인에 넣을 프로젝트 파일(JSON)을 만들어 준다. 사이트에서 직접 입력해도 결과는 같다.
같은 안내가 사이트 미션 탭의 **RFP로 자동 채우기** 버튼에 있다.

## 직원 — Claude에 스킬 설치 (한 번)

1. 사이트 미션 탭 → **RFP로 자동 채우기** → `thefrom-brain-project.zip` 받기. 압축을 풀지 않는다.
   (저장소에서는 `v2/skill/thefrom-brain-project.zip`)
2. Claude → 사용자 지정(Customize) → 스킬(Skills) → "+" → 스킬 만들기 → 스킬 업로드 → 받은 ZIP 선택.
3. 목록에 `thefrom-brain-project`가 보이고 켜져 있으면 끝이다.

스킬은 코드 실행 · 파일 생성이 켜져 있어야 쓸 수 있다(설정 → 기능).

## 관리자 — 조직 전체에 한 번에 배포 (Team · Enterprise 플랜)

조직 소유자가 조직 설정의 스킬 메뉴에서 같은 ZIP을 올리면 모든 구성원의 스킬 목록에 바로 나타난다. 이 경우 직원은 설치할 필요가 없다.

## 쓰는 법

1. 새 대화에 RFP · 팩트북 · 초안을 첨부한다.
2. "브레인 프로젝트로 만들어줘"라고 쓴다. 미션이 정해져 있으면 한 줄 덧붙인다.
   예: "미션은 RFP에 기반한 보안 · 인프라 중심 운영 플랜. 디자인은 이번엔 마이너."
3. Claude가 주는 JSON 파일을 받는다. 답에는 고른 분류, 비워 둔 필수 칸, 자료끼리 어긋나는 내용, 다 읽지 못한 자료가 적힌다.
4. 사이트 미션 탭 → **프로젝트 가져오기**로 올린다.
5. 칸을 확인하고 고친 뒤 실행한다.

## 다른 LLM (ChatGPT · Gemini 등)

1. **RFP로 자동 채우기**에서 지시문 파일을 받거나 복사한다(`skill/thefrom-brain-project/SKILL.md`).
2. 지시문과 자료를 같이 올리고 "이 지시문대로 브레인 프로젝트 파일을 만들어줘"라고 쓴다.
3. 답의 JSON을 `.json` 파일로 저장해 **프로젝트 가져오기**로 올린다.

## 올린 뒤 볼 것

- 자료에서 옮긴 팩트는 "자료에서 옮김 · 확인 전"으로 들어온다. 제안서에 쓸 수치는 원문을 보고 "원문 확인함"을 누른다.
- 이슈는 근본 1개와 하위 4개 안쪽으로 둔다. 이슈가 많을수록 실행이 길어진다.
- 클라이언트 자료는 회사가 허용한 LLM에만 올린다.

## 스킬을 고칠 때

`v2/skill/thefrom-brain-project/SKILL.md`를 고치고 `npm run skill:zip`으로 ZIP을 다시 만든다. 테스트가 ZIP이 최신인지 본다. 직원은 새 ZIP을 다시 올린다(조직 배포면 관리자가 한 번).
