# 가정한 브리프 — 가전 브랜드 고객 앱 리뉴얼

> 평가용으로 지어낸 브리프다. 실제 클라이언트가 아니다. 해법의 방향을 적지 않았다.

| | |
|---|---|
| 과업 | 중견 생활가전 브랜드의 고객 앱(제품 등록 · AS 접수 · 사용설명서)을 리뉴얼한다 |
| 목적 | 구매 뒤에도 고객과의 관계를 이어 가서 소모품 매출과 재구매를 늘린다 |
| 타겟 | 최근 5년 안에 이 브랜드의 가전(공기청정기 · 정수기 · 건조기 등)을 산 30~50대 가구 |
| 제품 · 서비스 | 고객 앱. 지금 기능은 제품 등록, AS 접수, 사용설명서, 공지 |
| 채널 | 모바일 앱, 제품에 붙은 QR, 구매 후 문자 |
| 제약 | 광고성 푸시를 늘리지 않는다. 개발 인력 4명, 기간 6개월. 제품 하드웨어는 바꾸지 않는다 |
| 성공 기준 | 한 달에 한 번 이상 앱을 여는 고객이 늘어난다 |

## 클라이언트가 준 내부 자료 (가정)
- 앱을 설치한 고객 가운데 90일 안에 다시 연 고객은 열 명 중 두 명이다.
- 앱을 여는 이유는 대부분 AS 접수와 사용설명서 확인이다.
- 브랜드는 필터 등 소모품 정기배송을 운영하지만 앱에서는 신청할 수 없다.
- 푸시 알림을 끈 고객이 절반을 넘는다.
