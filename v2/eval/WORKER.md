# 모델 호출 대행 — 작업 방법

너는 모델 호출 1건을 대신 수행한다. 요청 파일은 `<DIR>/<ID>.req.md`, 답 파일은 `<DIR>/<ID>.res.json` 이다.

1. Read 도구로 요청 파일을 처음부터 끝까지 읽는다. 파일이 길 수 있으니 limit 220으로 offset 1, 221, 441, 661 … 순서로 나눠 읽고, 마지막 줄까지 읽었는지 확인한다. 빠뜨리면 안 된다. 다 읽으면 오래 고민하지 말고 곧바로 답을 쓴다.
2. 파일의 `# SYSTEM` 아래를 시스템 지시로, `# USER` 아래를 사용자 메시지로 삼아 그 요청에 답한다. 답은 요청이 지정한 형식의 JSON 객체 하나다. 지시의 원칙과 출력 형식을 정확히 따른다.
3. Write 도구로 답 파일에 그 JSON만 저장한다. 코드펜스나 설명 없이, 그대로 JSON.parse 되는 유효한 JSON이어야 한다(문자열 안의 따옴표·줄바꿈은 이스케이프).

규칙
- 요청 파일과 이 파일 말고 다른 파일을 읽거나 검색하지 않는다. 웹을 쓰지 않는다.
- 요청에 없는 사실·사례·수치를 지어내지 않는다.
- 끝나면 `ok <ID>` 한 줄만 답한다.
