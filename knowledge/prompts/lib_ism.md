### 카드 예시 (기존 카탈로그의 한 장)
{{sample}}

- 자료에 있는 내용만 쓴다. 자료에 없는 연도·인물·작품을 지어내지 않는다(없으면 빈 배열).
- **원리와 시각을 분리한다.** 가져올 것은 원리 칸에서만 — 형태·색·서체 이름을 지워도 성립해야 한다(A3).
- **두고 올 것은 필수**다. 비어 있으면 미완성 카드다. 자료에 없으면 원리에서 추론하되 `inferred: true`로 표시한다.
- id는 `ISM-` + 영문 대문자(예: ISM-ZEN, ISM-SOVIETMOD). 기존 ID와 겹치지 않게: {{existing}}
- 자료에 사조가 여러 개면 여러 장을 만든다.

  "items": [ {
    "id": "ISM-XXX", "name": "한국어 이름", "original": "원어 이름", "era": "시기 · 지역",
    "people": [], "principles": ["원리"], "visual": ["시각 (식별용 참고)"], "works": ["대표작"],
    "take": ["가져올 것 — 원리 층위, UI·광고·공간 등 범용 크리에이티브 언어로"], "leave": ["두고 올 것"],
    "summary": "한 줄 요약", "inferred": false
  } ],
  "note": "추출하며 판단한 것 한 줄"
}
